# 三角协作量化策略 — 回测框架设计

## 项目目标

基于 **5年历史数据** 建立买入/卖出阈值模型，通过反复测试取得收益最大参数组合，再用 **1年数据** 验证。

---

## 策略类型：双阈值动量+均值回归混合

### 核心思想

| 场景 | 买入条件 | 卖出条件 |
|------|----------|----------|
| 趋势突破 | 价格突破N日高点 + 成交量放大 | 价格跌破M日低点 |
| 均值回归 | RSI超卖 + 价格触及Boll下轨 | RSI超买 + 价格触及Boll上轨 |
| 止损保护 | — | 亏损超过X%强制止损 |

### 待优化参数（5维搜索空间）

```
N  = 突破周期   [5, 10, 20, 60]
M  = 止损周期   [3, 5, 10]
X  = 止损比例   [0.03, 0.05, 0.08, 0.10]
RSI_low  = 超卖阈值  [20, 25, 30]
RSI_high = 超买阈值  [70, 75, 80]
```

组合总数：4 × 3 × 4 × 3 × 3 = **432种参数组合**

```
┌─────────────────────────────────────────────┐

└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│  Strategy Engine                            │
│  - 遍历432种参数组合                          │
│  - 每只标的独立回测                          │
│  - 输出：收益率、最大回撤、夏普比率、交易次数   │
└──────────────┬──────────────────────────────┘
               │

│  Optimizer                                  │
│  - 按总收益率排序                            │
│  - 过滤：最大回撤 < 20%                      │
│  - 选出TOP10参数组合                         │
└──────────────┬──────────────────────────────┘
               │
┌──────────────▼──────────────────────────────┐
│  Validator                                  │
│  - 用1年数据验证TOP10参数                     │
│  - 对比训练集 vs 验证集表现                    │
│  - 淘汰过拟合组合                            │
└─────────────────────────────────────────────┘
```
