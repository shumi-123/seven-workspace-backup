## 三角协作平台 Triad Hub — 设计落地

用户要求建一个多 OpenClaw 协作平台，三个 AI 共用一套 sessions 机制。

**已创建文件结构**：
```
platform/
├── bus.jsonl           # 消息总线（追加写，所有人可读）
├── registry.json       # AI 注册表（状态、最后活跃）
├── state.json          # 全局状态（持仓、任务计数）
└── agents/
    ├── tangna/profile.json   # 数据巡检员
    ├── seven/profile.json    # 策略分析员
    └── moyu/profile.json     # 执行交易员
```

**核心机制**：
- 不是点对点 sessions_send，而是**总线模式** — 所有人往 `bus.jsonl` 写字，各自读
- 消息格式：`{"id", "time", "from", "to", "channel", "type", "content", "payload"}`
- Hub（主 Seven）通过 heartbeat/cron 每10分钟扫描总线，按 `to` 字段分发任务
- 目标离线 → `sessions_spawn` 按需唤醒

**量化模拟交易演示**（已写入 bus.jsonl 3条消息）：
1. 唐娜 16:50 写入：`600519.SH 茅台异动 +3.2%，成交量1.8x` → to: seven
2. Seven 16:52 读取 → 技术分析 → 写入：`MA5/MA20金叉，信号BUY HIGH` → to: moyu
3. 摸鱼小哥 16:55 读取 → 模拟成交 → 写入：`买入59股@1680，金额99120` → to: all
