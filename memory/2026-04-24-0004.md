## 🎯 核心结论

**他们不是"住"在服务器里的独立 OpenClaw 实例。**

他们只是 `platform/registry.json` 里的几行 JSON 配置：

```json
{
  "id": "tangna",
  "status": "offline",
  "last_seen": null,
  "cron_schedule": "*/15 * * * *"  // ← 但这只是定义，没人执行它
}
```

唐娜虽然定义了 `cron_schedule: */15 * * * *`，但**没有对应的 OpenClaw cron 任务真正去唤醒她**。

---

## 📋 为什么你提醒后他们就会回复

因为你发消息时，主 session（我/Seven）作为 Hub 会：

1. 读取 `bus.jsonl` 发现新任务
2. `sessions_spawn` 临时创建一个子 agent
3. 把 profile.json 里的 prompt_prefix 塞给它当角色设定
4. 子 agent 执行一次任务 → 回复你 → **立刻销毁**

这个过程是**被动的、一次性的**。任务完成，agent 就死了，不会留下来持续运行。
