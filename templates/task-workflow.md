# AI任务管理流程

> **适用场景：** 人 + 多个AI协作的项目管理
> **目标：** 减少沟通成本，提高任务完成率

---

## 流程概览

```
人派发任务 → AI确认理解 → AI执行 → AI自检 → 人验收 → 归档
     ↑___________________________________________|
                    （返工循环）
```

---

## 第一步：派发任务（人）

**做什么：** 填写《任务派发模板》，发给指定AI

**关键动作：**
1. 打开 `templates/task-template.md`
2. 填写所有必填字段（背景、输入、输出、验收标准）
3. 明确截止时间
4. 发送给AI

**禁止：**
- ❌ 口头描述（"做个审计模块"）
- ❌ 缺少验收标准
- ❌ 没有输入数据/参考文档

---

## 第二步：确认理解（AI）

**AI必须回复：**

```
✅ 任务已接收 [TASK-ID]

理解摘要：
- 我要做：________
- 使用输入：________
- 输出到：________
- 验收标准：________
- 预计完成：________

疑问（没有则写"无"）：
1. ________
```

**人确认后才开始执行。**

---

## 第三步：执行（AI）

**执行中规则：**
1. 每完成一个里程碑，更新进度
2. 遇到阻塞超过30分钟 → 立即汇报
3. 不要假设，不确定就问

**进度更新格式：**
```
🔄 进度更新 [TASK-ID]
已完成：________
进行中：________
遇到的问题：________
预计完成时间：________
```

---

## 第四步：自检（AI）

**交付前必须做：**
1. 对照《验收清单》逐项自查
2. 运行所有测试用例
3. 检查敏感信息是否清理
4. 确认文件保存路径正确

**自检报告：**
```
🔍 自检报告 [TASK-ID]
- 功能测试：✅通过 X项 / ❌失败 X项
- 代码质量：✅通过 X项 / ❌失败 X项
- 文档完整性：✅通过 X项 / ❌失败 X项

需要人确认的问题：
1. ________
```

---

## 第五步：验收（人）

**验收动作：**
1. 对照《验收清单》逐项检查
2. 运行AI提供的测试用例
3. 检查交付物完整性

**三种结果：**

| 结果 | 动作 |
|------|------|
| ✅ 通过 | 确认完成，归档任务 |
| ⚠️ 有条件通过 | 列出需修复项，AI返工 |
| ❌ 不通过 | 说明原因，AI重新执行 |

---

## 第六步：归档

**归档内容：**
1. 任务模板（原始需求）
2. 交付物（代码/文档）
3. 验收清单（验收记录）
4. 经验教训（可选）

**归档路径：**
```
memory/
├── tasks/
│   ├── 2026-04/
│   │   ├── TASK-2026-04-20-001-完成.md
│   │   └── TASK-2026-04-20-002-进行中.md
```

---

## 紧急任务流程

**适用：** 🔴 紧急任务

**简化步骤：**
1. 人口头指派（允许简短描述）
2. AI立即执行（跳过确认环节）
3. 完成后补填任务模板
4. 快速验收（核心功能可用即可）

**注意：** 紧急任务比例不应超过20%。否则流程形同虚设。

---

## 返工规则

**什么情况下返工：**
- 未达到验收标准中的硬指标
- 输出格式与要求不符
- 缺少必要文档
- 发现安全/性能问题

**返工次数限制：**
- 常规任务：最多返工2次
- 第3次返工 → 人介入协助

**返工任务格式：**
```
🔄 返工 [TASK-ID] 第X次

未通过项：
1. ________（原因）
2. ________（原因）

修改要求：
1. ________
2. ________

截止时间：________
```

## 常见问题

### Q: AI说"理解了"但做出来不对
**原因：** 确认环节走过场。
**解决：** 要求AI复述任务要点，人确认无误后再执行。

### Q: 任务做到一半发现需求有问题
**原因：** 前期背景描述不清。
**解决：** 任务模板中"背景"字段必须填写。必要时提供用户故事。

### Q: AI交付后验收不通过，反复返工
**原因：** 验收标准不明确或AI未自检。
**解决：** 验收标准量化（"处理100条数据"而非"处理大量数据"）。强制自检环节。

### Q: 多个AI协作一个任务，互相等待
**原因：** 任务拆分不清晰。
**解决：** 使用"关联任务"字段明确依赖关系。并行列的任务同步执行，串行列的任务排好顺序。
