# 验收清单（Checklist）

> **使用说明：** AI完成任务后，指派人按此清单逐项检查。全部打勾才算通过。

---

## 一、功能性验收

### 1.1 核心功能
- [ ] 功能已实现且可运行
- [ ] 处理边界情况（空输入、大数据量、异常格式）
- [ ] 错误处理完善（有try-catch或错误提示）
- [ ] 无运行时错误和警告

### 1.2 输入输出
- [ ] 输入格式与任务要求一致
- [ ] 输出格式与任务要求一致
- [ ] 编码正确（UTF-8）
- [ ] 文件路径正确

---

## 二、质量验收

### 2.1 代码质量
- [ ] 有必要的注释（关键逻辑、复杂算法）
- [ ] 命名规范（变量/函数名有意义）
- [ ] 无硬编码敏感信息（Token、密码、密钥）
- [ ] 无调试代码（print、console.log已清理或改为日志）

### 2.2 文档质量
- [ ] README.md 包含：功能说明、安装步骤、使用示例
- [ ] 关键函数有 docstring/注释
- [ ] 变更日志（如有版本迭代）

### 2.3 测试
- [ ] 提供测试用例（至少3个）
- [ ] 测试覆盖正常路径
- [ ] 测试覆盖异常路径
- [ ] 附上测试结果截图或日志

---

## 三、合规性验收

### 3.1 安全
- [ ] 无敏感信息泄露
- [ ] API调用有错误重试机制
- [ ] 不会意外删除/修改生产数据

### 3.2 性能
- [ ] 运行时间在可接受范围
- [ ] 内存使用合理
- [ ] 不会导致死循环或资源耗尽

---

## 四、交付物完整性

### 4.1 必须交付
- [ ] 代码文件（已保存到指定路径）
- [ ] 测试文件或测试截图
- [ ] 文档（README或使用说明）

### 4.2 建议交付
- [ ] 架构/流程图（如任务复杂）
- [ ] 部署/配置说明
- [ ] 已知问题清单
