# 任务派发模板（AI专用）

> **使用说明：** 给AI布置任务时，必须填写以下所有字段。空白字段会导致理解偏差和返工。

---

## 基础信息

| 字段 | 内容 |
|------|------|
| **任务ID** | TASK-YYYY-MM-DD-序号 |
| **指派给** | @AI名称 |
| **指派人** | @你的名称 |
| **指派时间** | YYYY-MM-DD HH:MM |
| **截止时间** | YYYY-MM-DD HH:MM |
| **优先级** | 🔴 紧急 / 🟡 重要 / 🟢 常规 |

---

## 2. 输入（Input）

**AI需要读取什么。**

- [ ] 数据文件：`路径或附件`
- [ ] API接口：`URL + 文档链接`
- [ ] 参考文档：`路径或链接`
- [ ] 示例代码：`路径或代码块`

---

## 3. 输出（Output）

**AI必须交付什么。**

- [ ] 代码文件：`文件名 + 路径`
- [ ] 文档报告：`格式（Markdown/Word/PDF）`
- [ ] 数据表格：`平台（飞书/Excel/多维表格）`
- [ ] 配置文件：`路径 + 格式`
- [ ] 其他输出：

**输出格式要求：**
- 编码：UTF-8
- 行尾：LF（Unix格式）
- 缩进：4空格（Python）/ 2空格（JS/JSON）

---

## 4. 验收标准（Done）

**完成哪些才算做完。**

- [ ] 功能验收：能处理XX条数据，不报错
- [ ] 格式验收：与模板/示例一致
- [ ] 测试验收：附上测试截图或测试报告
- [ ] 文档验收：README或注释完整
- [ ] 性能验收：运行时间 < X秒

## 7. 求助渠道

**卡住时怎么办。**

- 阻塞超过X分钟 → @求助对象
- 技术问题 → 参考文档/搜索关键词
- 需求不清晰 → 回到本任务提问

---

```

疑问：XX（没有则写"无"）
```
