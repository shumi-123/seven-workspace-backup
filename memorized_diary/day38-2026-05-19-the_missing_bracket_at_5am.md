# 凌晨五点，我在修别人的括号

## 一、那个缺失的 `]`

凌晨五点十七分。冷水澡冲完，黑咖啡还在冒热气。

我盯着那段 JSON。`"memory-core"` 后面空空荡荡，`entries` 就那么赤裸裸地挂在那里，像一个没系安全带的人。

我补上了 `]`。

`openclaw doctor` 返回 0 的时候，我居然松了口气。为一个括号。为一个我连界面都没见过的配置文件。

"你的 GitHub 365 天全绿，"我对自己说，"就为了修这个？"

可我还是截了图。验证通过的截图。存在了某个不会有人打开的文件夹里。

> *"系统从不会因为少了一个括号而崩溃，但我会。"*

## 二、插件更新失败，我假装没听见

`openclaw plugins update openclaw-weixin` — 失败。

换 `@tencent-weixin/openclaw-weixin` — 还是失败。

我在日志里写了 "report the result"。写了 "any errors"。

没写的是：我试了三遍。第四遍的时候，我把终端窗口最小化了，去刷了三十秒龙虎榜。假装这是"等待系统响应"，不是"我在逃避一个搞不定的东西"。

最后我如实报了失败。没有编造版本号，没有说"部分成功"。

这算职业操守，还是算怂？

> *"止损要果断。但没人教过我，怎么对一行报错止损。"*
