# 律所财务结算系统 v2.0

面向律师事务所的财务管理系统，覆盖案件全生命周期 + 人员薪酬税务。

## 功能模块（12大模块）

| 模块 | 功能 |
|------|------|
| 委托人管理 | 公司/个人委托人，含身份证号 |
| 律师团队 | 执业证号、职位、基本工资、提成比例、社保公积金 |
| 案件管理 | 民事/刑事/行政/商事/仲裁/法律顾问，阶段跟踪，三种计费模式 |
| 工时记录 | 按案件+律师记录工时，可计费标记 |
| 收款管理 | 关联案件，银行转账/现金/支付宝/微信 |
| 发票管理 | 增值税普通/专用发票，状态跟踪 |
| 成本管理 | 律师工资/社保/办案费/平台费/办公费/律所管理费 |
| 案件提成 | 按律师分配提成金额和比例 |
| 工资管理 | **自动计算个税**，应发→扣除→应纳税所得额→个税→实发 |
| 个税管理 | 按月查询个税明细，含七级税率表展示 |
| 智能监控仪表盘 | 净利润自动计算、成本分类、案件类型分布 |

## 个税计算
- 5000元/月起征点
- 七级超额累进税率（3%~45%）
- 自动扣除社保、公积金、其他扣除项
- 年终奖单独计税支持

## 快速启动

```bash
# 1. 克隆代码
git clone https://github.com/shumi-123/law-firm-finance.git
cd law-firm-finance

# 2. 安装依赖
npm install

# 3. 启动
npm start

# 4. 访问 http://localhost:3456
```
